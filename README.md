# ✨ Étoile – The Art of Capturing Light

**Étoile** is a luxury jewelry and accessories website inspired by the timeless elegance of Paris.  
The project showcases a refined digital boutique where craftsmanship, storytelling, and modern design converge.  

## 🌟 Features

- **Elegant Landing Page**  
  Immersive hero section with background video and the brand’s motto: *“The art of capturing light.”*

- **Collections**  
  - **Jewelry:** Rings, necklaces, bracelets, and earrings blending French tradition with contemporary design.  
  - **Accessories:** Luxury tiaras, brooches, and crystalized details, all handcrafted in Parisian workshops.  
  - **New Arrivals:** A dedicated section highlighting the latest creations and seasonal promotions.

- **Responsive Layout**  
  Designed with clean, semantic HTML and CSS for a seamless browsing experience across devices.

- **Brand Identity**  
  Every page conveys the essence of French artistry — combining noble materials, artisanal heritage, and modern aesthetics.

## 🛠️ Tech Stack

- **HTML5** for semantic structure  
- **CSS3** for styling and responsive design  
- **Media Integration** (video & images) to create a luxurious and immersive atmosphere
